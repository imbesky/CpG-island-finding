# Raw Data Instructions

Due to database license agreements and file size limitations, raw genomic files are not tracked in this repository. 
Please download the required files from the official sources below and place them in this folder before running the pipeline:

1. **Arabidopsis thaliana (TAIR10)**
   - Source: [TAIR Download Center](https://www.arabidopsis.org)
   - File: `TAIR10_upstream_1000_20101104.fasta`, `TAIR10_GFF3_genes.gff`
2. **Brassica rapa (cv. Chiifu, v4.0)**
   - Source: [BRAD Database](http://brassicadb.cn/)
   - File: `Brapa_genome_v4.0_chrom.fasta`, `Brapa_genome_v4.0_gene.gff3`
3. **Brassica juncea (var. tumida, v2.0, inferred from file naming)**
   - Source: [BRAD Database](http://brassicadb.cn/)
   - File: `BjuT84V2.fa`, `BjuT84V2.gff`
